### 0.2 本次设计要达成的两个目标

1. **视频页分页自动化**：默认仍是「本地视频」与「局域网 / 网络源」各占半页同屏；当某一区的内容高度达到一页可用高度时，该区自动升级为独立整页，进入分页模式。
2. **页签胶囊可回缩**：底部页签胶囊停留一段时间后自动回缩为悬浮小胶囊，点击即展开；回缩时长由「设置 → 外观 → 页签悬浮」滑杆控制（0~60 秒，0 为常驻）。

### 0.3 设计原则

- **内容优先**：一切留白与占位以"内容不被遮挡、可点区域不小于 48vp"为硬约束。
- **不打断播放**：胶囊与分页的一切行为不得中断视频播放、不得抢占播放页手势。
- **可回退**：分页判定与胶囊回缩均须提供"回到原形态"的路径（删除视频后回落、点击展开、滑杆置 0 常驻）。
- **零侵入存量逻辑**：复用现有 `viewH / pageHeight() / overlayTop() / flipLock / swiperCtrl` 等基础设施，不重写视频页骨架。

## 一、视频页分页规则设计

### 1.1 两种形态定义

| 形态 | 触发条件 | 布局 | 翻页 |
| --- | --- | --- | --- |
| **同屏形态（stacked）** | 本地区与网络区**均未**占满一页 | 单 `Scroll` 纵向滚动，上「本地视频」下「局域网 / 网络源」，各占约半页 | 不需要翻页，靠滚动查看 |
| **分页形态（paged）** | **至少一区**内容高度 ≥ 一页可用高度 | `Swiper` 竖直（或按现有实现）多页，每页一个区，页内独立滚动 | 页内滚到边界后继续滑动翻页 |

> 说明：现状是"有本地视频就走分页"，与本次"按内容高度判定"不同。本次改造要把触发条件从 `hasLocal()` 升级为 `isPaged()`（内容高度判定结果），`hasLocal()` 仅作为前置条件之一保留。

### 1.2 关键度量定义

必须先统一"一页可用高度"的口径，否则判定会在不同机型上漂移。

```
H_screen     = 屏幕物理高度（vp）
H_top        = 顶部工具栏 / 状态栏安全区实际占用高度（含 AppTheme 的页面内边距）
H_bottom     = overlayTop() = 74 + safeBottom （胶囊 52 + 底距 14 + 安全区）
H_avail      = H_screen - H_top - H_bottom     ← 一页可用高度（单一信源）
```

实现约定：

- `H_avail` 由 `pageHeight() - overlayTop()` 派生，其中 `pageHeight()` 已实测（`viewH`），不得再自行拼接屏幕高度常量。
- 现状 `netSectionHeight()` 里的魔法数 `48`（顶部标题行占位）应在本次统一成一个具名常量（如 `SECTION_HEADER_H`），供两区共用，避免两套口径。
- `H_avail` 建议向下取整到整数 vp，避免亚像素输入导致判定抖动。

### 1.3 "占满"判定与阈值

- **判定对象**：某一区的**实际内容高度** = 区标题行高度 + 该区列表实际内容高度（不含滚动容器的空白填充）。
- **判定公式**：`full = contentH >= H_avail * FULL_THRESHOLD`，`FULL_THRESHOLD = 0.98`。
- **阈值理由**：0.98 让"内容几乎贴满但仍差几像素"也进入分页，避免用户反复滑动却看不见全部内容；同时留 2% 缓冲吸收字体度量、行高取整、边框等亚像素误差。
- **去抖（必须）**：
  - 判定结果写入前与上一次结果比较，相同则不触发任何状态变更与重排。
  - 由"占满 → 未占满"的回退需**再确认一次**（下一次重算仍不满足才回落），避免临界抖动导致布局来回跳。
  - 分页/同屏切换必须做**最小滞留时间**保护（建议 300ms），期间不做形态切换。
- **测量口径陷阱**：取"滚动容器的 `contentHeight`"，不要取 `Scroll` 组件的 `height`（后者恒等于容器高，永远是 100%），否则判定恒为占满。

### 1.4 测量方式

| 对象 | 方法 | 说明 |
| --- | --- | --- |
| 页面可用高度 | 沿用 `Stack.onAreaChange` → `viewH` | 现状已实现，改动最小，保持单一信源 |
| 本地区内容块 | 在本地区外层容器挂 `onAreaChange`（或 `onSizeChange`） | 读取 `newValue.height` 作为 `localContentH`；容器须为 `Column` 自适应高度，禁止固定 `height` |
| 网络区内容块 | 在 `NetPanel` 外层容器挂 `onAreaChange` | 读 `netContentH`；`netBrowsing` 放大态下的实测值不参与分页判定（见 1.8） |
| 列表实际内容高度 | 优先用容器实测；若列表用 `List` 且内部虚拟化导致高度不准，改用 `onScrollIndex` + 行高估算，并在文档中标注该区为"估算口径" | 视频本地列表为 `previewRows/previewCount` 限量展示，可直接用容器实测 |

实现注意：

- `onAreaChange` 回调**不得**在回调内直接改会再次触发布局的 `@State`（易成环），应"记录测量值 + `setTimeout(0)` 或任务队列中统一调度重算"。
- 测量值变化小于 1vp 视为噪声，忽略。
- 首次布局前 `contentH = 0`，此时**不得**判定为"未占满"并强制回落到同屏，应保持"待定"状态，等首帧测量完成后再定形态（避免首屏闪烁）。

### 1.5 重算触发时机（必须全量覆盖）

| 序号 | 时机 | 说明 |
| --- | --- | --- |
| 1 | 首次加载 / 首帧布局完成 | `viewH` 首次写入且 `> 0` 后触发一次 |
| 2 | 导入视频后 | `items.length` 变化后触发 |
| 3 | 删除视频后 | 同上，且删除可能触发"占满 → 未占满"回落 |
| 4 | 网络源目录加载完成 | 目录列表从空到有、或项数变化 |
| 5 | 横竖屏切换 / 窗口尺寸变化 | `viewH` 变化必然触发 |
| 6 | 字体缩放 / 显示大小变化 | 行高变化，需重新测量（可用 `mediaquery` 监听配置变化） |
| 7 | 搜索态切换 | 本地区进入/退出 `searching` 时内容高度会变（现状 `inlineSearch()` 插入搜索框） |
| 8 | `netBrowsing` 切换 | 退出目录浏览回到列表态时重算 |
| 9 | 折叠/展开类交互 | 若后续加入折叠区，需同样触发 |

> 触发统一收敛到**一个** `recalcPaging()` 方法，任何来源只调它，避免多处逻辑分散。

### 1.6 分页状态机

```
状态：pending（待定） → stacked（同屏） ⇄ paged（分页）

pending --首帧测量完成 & 两区均未占满--> stacked
pending --首帧测量完成 & 任一区占满--> paged
stacked --内容增长致任一区占满--> paged（最小滞留 300ms 后）
paged   --内容减少致两区均未占满（需二次确认）--> stacked
```

状态字段建议（命名可调整，语义不得变）：

- `@State paged: boolean`
- `@State localContentH: number`
- `@State netContentH: number`
- `@State pagingPending: boolean`（待定标记）
- `私有 lastSwitchAt: number`（最小滞留时间用）

派生方法：

- `isPaged(): boolean` → 供 `build()` 替换现有 `if (this.hasLocal())`
- `hAvail(): number` → `pageHeight() - overlayTop()`
- `localFull(): boolean` / `netFull(): boolean`

### 1.7 分页手势与翻页触发

沿用现状机制，只调整触发条件：

- **翻页条件**：列表滚到边界（`scroll.isAtEnd()` / `isAtStart()`）后继续同向滑动，且当前处于 `paged` 形态。
- **翻页实现**：`flipTo(target)` → 置 `flipLock = true` → `swiperCtrl.changeIndex(target, true)` → `setTimeout(420)` 解锁。冷却锁 420ms 保留不变（与 `Swiper` 320ms 动画留 100ms 容差）。
- **动画**：`Swiper.duration(320)`、`Curve.EaseOut` 保持；不新增 Bounce/回弹效果，避免与 `EdgeEffect.Spring` 冲突。
- **反向翻页**：网络页在顶部继续下滑 → `pullBackToLocal()`（现状已有，保留）。
- **边界不越界**：`target < 0 || target > 1` 直接拒绝，不做循环翻页。
- **同屏形态下**：手势只滚动，不翻页（`flipTo` 入口增加 `paged` 判定）。
- **单区独存**：若只有一区占满而另一区为空（如未导入本地视频、只浏览网络），仍允许保留"另一个整页的空态"，但**禁止**在空页触发起始翻页动画级别的抖动——沿用现状 `emptyBlockHeight()` 空态处理即可。

### 1.8 两区都占满时的页序与页码指示

- **页序固定**：第 1 页（index 0）= 本地视频；第 2 页（index 1）= 局域网 / 网络源。不因高度大小改变顺序，保证肌肉记忆。
- **页码指示**：两区都占满时，在**页内右上角**（或页标题行右侧）显示 2 点的页点指示器（当前页实心、另一页 `textTertiary` 空心），高度 ≤ 12vp，不参与点击。
  - 禁止把指示器放在底部，避免与胶囊 `overlayTop()` 占位冲突。
  - 单区占满时**不显示**页点指示器（避免暗示还有一页）。
- **胶囊不随页切换移动**：胶囊为全局浮层，翻页时位置与状态不变（回缩态保持回缩，展开态保持展开）。
- **`netBrowsing` 特例**：进入网络目录浏览时网络区放大（`netFillHeight()`），此放大属于"瞬态放大"，**不参与分页判定**，退出浏览态后按真实内容高度重算。

### 1.9 边界情况处理

| 情况 | 期望行为 |
| --- | --- |
| 无任何视频、无网络配置 | `stacked`，两区都显示空态，不出现翻页手势 |
| 仅本地视频且很少 | `stacked`（本地半屏 + 网络半屏） |
| 仅本地视频且很多 | `paged`，本地占第 1 页；第 2 页为网络区 |
| 删除到只剩少量 | 二次确认后回落 `stacked`，当前页归零（`videoPage = 0`），`swiperCtrl` 重置索引 |
| 搜索态（关键字过滤后列表变短） | 退出搜索后重算；搜索中若内容变短**不立即**回落（避免边打字边跳布局），仅在退出搜索时重算 |
| 横竖屏切换 | 立即重算；`H_avail` 变化后阈值随之变化，不得沿用旧值 |
| 字体放大到超大 | 允许形态切换频繁，但受 300ms 最小滞留保护 |
| 折叠屏 / 分屏 | `viewH` 变化即重算，行为同上 |

## 二、页签胶囊悬浮回缩设计

### 2.1 状态定义

| 状态 | 形态 | 进入方式 |
| --- | --- | --- |
| `expanded`（展开） | 现状三页签完整胶囊：宽 `86%`（宽屏 420，上限 460）、高 52、圆角 26 | 初始态；点击回缩态；切换页签后 |
| `collapsed`（悬浮小胶囊） | 小型悬浮胶囊：保持玻璃底与模糊，直径/高度约 44~48vp，仅显示"当前页签标识"（当前页签文字，或三点省略形态） | 停留达设定时长后自动回缩 |
| 过渡 | `600ms` 内不响应二次点击（防抖），动效期间 `hitTestBehavior` 保持可点 | — |

### 2.2 回缩时机规则

1. **进入页面**：切换到视频 / 音乐 / 设置任一页后，胶囊先呈展开态，停留 `T` 秒（`T` = 设置滑杆值）后自动回缩。
2. **点击回缩胶囊**：立即展开，并**重置计时**；展开后 `T` 秒无操作再次自动回缩。
3. **展开态内的任何有效操作都会重置计时**：点击其他页签、`switchTab()`、页面滚动不算操作（避免滚动时胶囊一直保持展开）；只有"触摸胶囊本身"重置计时。
4. **`T = 0`**：常驻展开，永不自动回缩（计时器不启动）。
5. **切页 / 切前后台**：切页重置计时为展开态 + 重新计时；应用回前台重新计时。
6. **视频播放中**：仍按 `T` 回缩（不特殊延长），但回缩态必须不遮挡进度条与手势热区（见 2.5）。

### 2.3 动效规格

| 属性 | 展开 → 回缩 | 回缩 → 展开 |
| --- | --- | --- |
| `scale` | 1.0 → 0.34（≈ 52vp → 18vp 视觉体积，含内部文字缩略） | 0.34 → 1.0 |
| `opacity` | 1.0 → 0.94（保留玻璃感，不做隐没） | 0.94 → 1.0 |
| 宽度 | `86%`/420 → 48vp（固定，右对齐或居中保持位置不跳） | 反向 |
| 圆角 | 26 → 24 | 反向 |
| 位移 `translateY` | 0 → 0（不位移，避免与底部安全区冲突）| 0 |
| 时长 | 220ms（回缩）/ 240ms（展开） | — |
| 曲线 | `Curve.Friction`（回缩）/ `Curve.EaseOut`（展开） | — |
| 背景 | 保持 `capsuleColor()`（`pal().glassPlate`，85% 玻璃底）与 `backgroundBlurStyle(BlurStyle.Thick)` 不变 | 同 |

> 关键约束：**回缩只改变尺寸与视觉，不改变锚点与 `overlayTop()` 占位值**。即列表底部留白仍按 74 + safeBottom 计算，回缩后不回收留白，避免内容突然下移产生跳动。

### 2.4 回缩态视觉与可点性

- **视觉**：48vp 圆形/胶囊，玻璃底 + Thick 模糊 + 0.5vp 描边 + 阴影保持，内部只放"当前页签一个字"（视频/音乐/设置）或当前页签图标位；文字 12sp，居中。
- **可点击区域最小 48vp**：组件视觉 44vp 时，用 `.hitTestBehavior` 与外层透明容器把点击热区补到 **≥ 48×48vp**；禁止用 `.scale()` 缩小点击热区（`scale` 不影响热区，但视觉过小会误导，需以 48vp 热区兜底）。
- **不遮挡内容**：回缩态仍位于底部居中/右侧固定锚点（沿用现状 `Stack alignContent: BottomEnd` + `Column` 居中），底部留白不变，因此不会新增遮挡。
- **不改变布局**：胶囊容器外层 `.hitTestBehavior(HitTestMode.Transparent)`（现状已如此）需保留，确保胶囊以外的空白区域不拦截页面手势。
- **触摸穿透**：胶囊本体正常响应点击；胶囊**周围透明区域必须穿透**，否则回缩后会给页面底部造出一块死区。

### 2.5 不遮挡 / 手势安全区

- 回缩态中心点与底边距离保持现状 `14 + safeBottom`，回缩后底部空出的横向空间不得用于任何其他浮层（避免二次遮挡）。
- 若后续视频页出现底部进度条（播放页形态），胶囊回缩态须整体上移至少 `12vp` 或自动隐藏（该场景列入"待确认"，见 5.1）。

### 2.6 无障碍

| 项 | 要求 |
| --- | --- |
| `accessibilityText` | 展开态：当前页签项读作「页签：视频，已选中」；回缩态读作「页签已回缩，点按展开」 |
| `accessibilityLevel` | 设为可聚焦（`"yes"`），保证 TalkBack 能停留 |
| `accessibilityDescription` | 说明"长按不生效，单击展开" |
| 动效偏好 | 系统开启"减少动画"时，回缩/展开改为 0ms 直接切换（不做缩放动画） |
| 触控目标 | ≥ 48×48vp，见 2.4 |

### 2.7 深浅色与宽屏

- 深/浅色：沿用 `pal().glassPlate` 与描边色（深色 `#33FFFFFF` / 浅色 `#1F000000`），回缩态不新增硬编码颜色。
- 宽屏（`isWide`）：展开态宽度 420（max 460）保持；回缩态固定 48vp 且**贴右下**（`Alignment.BottomEnd` 内边距 `pagePadding`），避免平板中央回缩胶囊遮挡字幕/内容。

## 三、新增设置项「页签悬浮」

### 3.1 位置

- 文件：`entry/src/main/ets/view/SettingsPanel.ets`
- 分组：`设置 → 外观`，**紧跟现状「深浅色」区块之后**（在「深浅色」的 `Divider()` 之前插入，或将新项放在 `themeChip` 行之后、`Divider()` 之前，保持"外观"组内聚）。
- 不放进「本地视频设置」「音乐设置」「TV 设置」等折叠组，属于全局外观项。

### 3.2 形式与参数

| 参数 | 取值 |
| --- | --- |
| 控件 | `Slider`（`SliderStyle.OutSet` 或 `InSet`，与现有视觉统一，建议 `OutSet` 细轨） |
| 标签 | 页签悬浮 |
| 副标题 | `停留多久后自动回缩为小胶囊；0 表示常驻展开` |
| 取值范围 | 0 ~ 60（单位：秒） |
| 步长 | 1 |
| 默认值 | 1 |
| 当前值显示 | 右侧或副标题下方实时文本：`N 秒`；`N = 0` 时显示 `常驻` |
| 轨道配色 | `pal().divider`（未选中）/ `pal().primary`（已选中），滑块 `pal().primary` |
| 布局 | 与「深浅色」一致：`padding({ left: pagePadding, right: pagePadding, top: 8, bottom: 10 })`，占满宽度 |
| 轻提示 | 拖动结束时（`onChange` 的 `SliderChangeMode.End`）无需 Toast，静默保存 |

### 3.3 交互细节

- **实时预览**：滑杆拖动过程中（`mode = Begin/Moving`）把值写入运行时状态（`@StorageProp`/`AppStorage`），胶囊计时器**立即按新值重排**，用户可在设置页切回视频页前就感知效果（需保证 Index 监听同一状态）。
- **持久化时机**：仅在 `SliderChangeMode.End`（松手）或 `Click` 时调用 `PlayerPrefs.setCapsuleRetract(v)`；拖动过程中不写偏好，避免频繁 flush。
- **0 = 常驻**：值为 0 时不启动计时器；滑杆左侧可加刻度文字 `0 常驻`、右侧 `60 秒`（可选）。
- **禁用态**：无（该功能不依赖任何前置条件）。
- **键盘/遥控**：`Slider` 原生支持方向键步进 1 秒，无需额外适配；步进后同样在"结束"时持久化。

### 3.4 与现有设置项的一致性

- 文案层级复用现状：主文案 15sp `textPrimary`，副文案 12sp `textSecondary`。
- 分隔线复用 `Divider().color(this.pal().divider)` + `pagePadding` 左右内边距。
- 不使用折叠组包裹，保证"外观"三项（深浅色 / 页签悬浮）一屏可见。

## 四、持久化设计

### 4.1 键定义

| 项 | 值 |
| --- | --- |
| 存储 | `preferences`，`STORE_NAME = 'player_settings'`（复用 `PlayerPrefs`，不新建 store） |
| 键名常量 | `KEY_CAPSULE_RETRACT = 'capsule_retract_sec'` |
| 类型 | `number`（秒） |
| 默认值 | `1` |
| 合法范围 | `0 ~ 60` 整数 |
| 0 语义 | 常驻展开，不自动回缩 |

### 4.2 读写 API（`model/PlayerPrefs.ets` 新增，方向）

- `static getCapsuleRetractSec(): number`
  - 内部调用现有私有 `getNumber(KEY_CAPSULE_RETRACT, 1)`。
  - **兜底**：`Number.isFinite` 校验 → `Math.round` 取整 → `clamp(0, 60)`；非法（`NaN`、负数、`> 60`、字符串型脏值）一律回落到 1 并**顺手写回**一次修正值（避免每次读取都走兜底分支）。
- `static async setCapsuleRetractSec(v: number): Promise<void>`
  - 先 `clamp` + 取整再 `putNumber`，保证写入值恒合法。
- 不新增 `KEY_CAPSULE_*` 之外的键（如"上次是否回缩"这类运行态不持久化）。

### 4.3 版本迁移

- 现状 store 无版本号字段。本次**不加版本号**，采用"缺键即默认"策略：老版本升级后读不到该键 → 返回默认 1，行为与"新装即默认 1 秒"一致，无需迁移脚本。
- 未来若默认值变更，仅需在 `getCapsuleRetractSec()` 内做一次"键存在性判断"分支，本方案预留该扩展点。

### 4.4 读取时机与变更通知

| 环节 | 做法 |
| --- | --- |
| 应用启动 | `EntryAbility` 中 `PlayerPrefs.init(context)` 之后立即读取一次，写入 `AppStorage`：`AppStorage.setOrCreate('capsuleRetractSec', v)` |
| `Index` 使用 | `@StorageProp('capsuleRetractSec') capsuleRetractSec: number = 1`，值变化时 `@StorageProp` 自动触发重排计时器（`onChange` 逻辑放在 `aboutToAppear` 的 watch 或 `@Watch`） |
| `SettingsPanel` 使用 | 同样 `@StorageProp` 作为滑杆初值；拖动时写 `AppStorage`，松手写 `PlayerPrefs` |
| 变更通知方式 | 统一走 `AppStorage`（单向数据流：设置页写 → Index 读），不引入事件总线/回调链，避免跨组件耦合 |
| 异常保护 | `PlayerPrefs.store` 未初始化时 `getNumber` 返回默认值，需保证 UI 有值可用（默认 1），不出现 `undefined` 滑杆 |

> 一致性注意：`SettingsPanel` 与 `Index` 必须读**同一个** `AppStorage` 键，禁止各自 `PlayerPrefs.get` 后在内存里分裂成两份状态。

## 五、交互边界

### 5.1 视频播放相关

| 场景 | 胶囊行为 |
| --- | --- |
| 视频播放中（视频页内预览播放） | 仍按 `T` 回缩；回缩态不得遮挡画面控制条；若与底部控制条重叠，回缩态整体上移 12vp |
| 全屏 / 横屏播放（播放页） | 胶囊**不显示**（播放页为独立路由，视频页浮层不参与）；返回视频页后恢复展开态并重新计时 |
| 拖动进度条 / 手势快进 | 视频页无进度条；播放页不受影响。若后续视频页加入进度条，则"拖动中不触发回缩"，松手后重新计时 |
| 正在翻页（`flipLock = true`） | 胶囊可点击但不中途改变尺寸（避免与翻页动画叠加），翻页结束（420ms）后恢复计时 |
| 视频删除中 / 确认弹窗 | 胶囊保持当前状态，弹窗期间不自动回缩（`promptAction` 弹窗为系统层，不影响，但不要主动触发重排） |

### 5.2 列表与选择态

| 场景 | 行为 |
| --- | --- |
| 多选态（`selectionMode = true`） | 胶囊回缩后仍需可见可点（切页/退出多选都要用）；建议多选态**强制展开**并暂停计时，退出多选后重新计时 |
| 搜索态（`searching = true`） | 搜索输入中暂停回缩计时（避免胶囊在打字时缩小导致误触），退出搜索后重新计时 |
| 列表滚动 | 不重置计时（否则用户一直滚动，胶囊永不回缩，违背设计初衷） |
| 目录浏览态（`netBrowsing`） | 正常按 `T` 回缩；回缩后底部留白不变，目录最后一项仍可完整可见 |

### 5.3 主题与设备适配

| 项 | 要求 |
| --- | --- |
| 深色 | 玻璃底 `glassPlate` + `#33FFFFFF` 描边；回缩态不降低对比度到不可辨（`opacity ≥ 0.9`） |
| 浅色 | `#1F000000` 描边，阴影减弱（`#1A000000`），避免脏雾感 |
| 平板 / 宽屏（`isWide`） | 展开态 420（max 460）；回缩态固定 48vp 贴右下（`pagePadding` 内边距），不居中；分页页点指示器保持页内右上 |
| 折叠屏 / 分屏 | `viewH` 变化 → 重算分页与 `H_avail`；胶囊锚点随 `safeBottom` 更新 |
| 字体缩放 | 胶囊文案随系统字号放大，回缩态文字超长时截断为单字，不换行 |

### 5.4 跨页一致性

- 三页（视频 / 音乐 / 设置）共用同一胶囊实例（`Index.build()` 底部浮层），因此"回缩状态"是全局的：在设置页回缩后切到视频页仍是回缩态，直到点击展开。
- 音乐页现状 `MusicPanel({ capsuleReserve: this.overlayTop() })` 依赖 `overlayTop()`，因回缩不改占位，无需改动该参数。

### 9.2 与设计稿的差异（有意为之）

| 设计稿 | 实际实现 | 原因 |
| --- | --- | --- |
| 回缩动效用 `scale 1.0→0.34` + `opacity` | 用 `width/height/borderRadius` + `animation(220/240ms, Curve.EaseOut)` | 直接改尺寸不会与内容裁切叠加二次缩放，回缩态内部三点不会缩得过小；`opacity` 保持 1，玻璃底对比度更稳 |
| 回缩态显示"当前页签单字" | 显示三点标记、当前页签点高亮 | 48vp 内竖排单字可读性差，三点更接近"胶囊收起"的隐喻 |
| 本地区内容高度实测 | 本地区用行数 × 行高估算（`SECTION_HEADER_H + rows × VIDEO_ROW_H`），网络区用 `onAreaChange` 实测 | 本地区为限量预览行（`previewRows`），行高固定，估算口径稳定且避免首帧测量环 |
| 设置项为纯滑杆 | 滑杆 + 快捷 chip | 车机上滑杆精细拖动不便，chip 一击到位；两者共用同一状态 |
