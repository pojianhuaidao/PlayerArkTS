# 界面与交互实现说明

本文记录多媒体（`tv.hm.o`）播放主链路的界面组成、交互实现与关键 API 落点，供后续维护与二次开发对齐。

## 一、页面与组件分工

| 界面层 | 实现文件 | 组成 |
| --- | --- | --- |
| 媒体列表主界面 | `pages/Index.ets` | `buildToolbar()` + 隐藏 bar 的 `Tabs` + `List` + 悬浮 `fab()` + 自绘胶囊页签 `capsuleBar()` |
| 列表行 | `Index.ets` 的 `videoRow()` + `ThumbView` | 128×72vp 首帧封面 + 标题 + 时长/大小/分辨率两行元信息 |
| 播放页容器 | `pages/PlayerPage.ets`（网络/通用）与 `pages/LocalPlayerPage.ets`（本地独立播放页） | `Stack`：`XComponent` + 字幕层 + 手势层 + 控制层 |
| 控制层 | `PlayerCore.ets` 的 `topBar()` / `centerBar()` / `bottomBar()` | 顶部标题/返回/锁定/投屏，中部 -10s / 播放暂停 / +10s，底部进度条 |
| 轨道选择弹窗 | `PlayerCore.ets` 的 `showAudioTrackMenu()` 等 | 音轨、字幕轨以 `ActionMenu` 承载 |
| 列表项菜单 | `Index.ets` 的 `showItemMenu()` | 播放、信息、从列表移除 |

## 三、界面规范要点

1. **页签**：`Tabs` 的 bar 隐藏（`barHeight(0)`），自绘胶囊四等分（视频 / 音乐 / 网络 / 设置），选中项主题色实心胶囊；胶囊 72% 不透明 + 外描边 + 阴影，`hitTestBehavior(HitTestMode.Transparent)` 保证空白处事件穿透。
2. **安全区**：页面统一读 `safeTop / safeBottom`（`@StorageProp`），内容区底部让出 `112vp + safeBottom`，胶囊下留 `14vp + safeBottom`，顶栏 `expandSafeArea` 避让状态栏与挖孔。
3. **覆盖层**：禁止全屏透明容器压在 `Tabs` 之上；悬浮按钮以 `Stack({ alignContent: Alignment.BottomEnd })` 条件渲染，避免吞掉整屏触摸。
4. **深浅色**：`AppTheme.palette(isDark)` 取色板，页面以 `@StorageProp('isDark')` 驱动刷新，切换即时生效无需重启。
5. **横竖屏**：`orientation: unspecified`，布局按宽度自适应（手机/宽屏两套宽度上限）。

## 四、扩展约定

- 新增页面必须在 `resources/base/profile/main_pages.json` 注册，否则 `router.pushUrl` 静默失败。
- 面板类组件放 `ets/view/`，可路由页面放 `ets/pages/`；页面内不直接持有业务数据，统一走 `model/` 或 `lx/core/`。
- 任何新增的覆盖层都要复核第 3 条，历史上「点啥都没用」均由全屏透明覆盖层导致。
